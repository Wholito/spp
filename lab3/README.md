# Лабораторная № 3

Для отправки настоящих писем скопируйте `.env.example` в `.env` в этой папке. Заполните `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` и `SMTP_FROM` значениями вашего почтового провайдера. Для порта 465 установите `SMTP_SECURE=true`, для порта 587 оставьте `false`. В `ADMIN_EMAIL` укажите почту, которую вы можете открыть, а в `ADMIN_PASSWORD` задайте пароль администратора. Не добавляйте `.env` в Git.

Запустите приложение командой `docker compose up --build` из этой папки и откройте `http://localhost:8080`. Код подтверждения входа, ссылки приглашения и восстановления отправляются через указанный SMTP. Если SMTP недоступен, сервер вернёт ошибку `503`.

Логика кода входа и истории находится в `server/routes/secondFactor.js`. Приглашения находятся в `server/routes/invitations.js`. Отправка почты находится в `server/lib/mailer.js`. Интерфейс этих функций находится в `client/security.js`.
